# VI Notes

A note-taking web application built using React, Vite, Express, MongoDB and JWT authentication.

## Features
- User registration and login
- Secure authentication using JWT
- Create and save notes
- Database storage with MongoDB
- Responsive frontend

## Tech Stack
Frontend:
- React
- Vite

Backend:
- Express.js
- MongoDB
- JWT
- Node.js
